## 1. 对象的概念

**对象（Object）** 是现实世界中具体存在的事物在计算机中的映射。

| 现实世界 | 计算机世界 |
|----------|-----------|
| 一个具体的人（张三） | 一个对象 |
| 人的属性（姓名、年龄、身高） | 对象的**成员变量**（属性） |
| 人的行为（吃饭、走路） | 对象的**方法**（行为） |

### 对象的特征

- **具体性**：对象是具体存在的，不是抽象的
- **有属性**：描述对象的状态
- **有行为**：描述对象能做什么

> 举个例子："张三"是一个对象——他有名字、年龄等属性，能吃饭、走路。

## 2. 类与对象的关系

### 类（Class）—— 对象的模板

**类** 是对一类事物的抽象描述，定义了该类事物共有的属性和行为。

### 对象（Object）—— 类的实例

**对象** 是根据类这个模板创建出来的具体个体。

### 比喻

```
类（Class）        = 一张建筑设计图纸
对象（Object）     = 按照图纸盖出来的具体房子

一张图纸 → 可以盖出无数栋房子
一个类   → 可以创建出无数个对象
```

### 区别

| 对比 | 类（Class） | 对象（Object） |
|------|-------------|---------------|
| 抽象/具体 | 抽象的模板 | 具体的实体 |
| 内存占用 | 方法区（不占堆） | 占用堆内存 |
| 数量 | 定义一次 | 可创建多个 |
| 作用 | 定义属性和行为 | 存储数据并执行行为 |

## 3. 定义类的步骤

### 第一步：设计对象模板（类）

```java
修饰符 class 类名 {
    // 1. 成员变量（属性）
    数据类型 变量名;
    数据类型 变量名;
    ...

    // 2. 成员方法（行为）
    修饰符 返回值类型 方法名(参数列表) {
        // 方法体
    }
}
```

### 示例

```java
public class Student {
    // 成员变量
    String name;
    int age;
    double score;

    // 成员方法
    public void study() {
        System.out.println(name + "正在学习");
    }

    public void sayHi() {
        System.out.println("大家好，我是" + name);
    }
}
```

### 命名规范

| 元素 | 规范 |
|------|------|
| 类名 | 大驼峰，首字母大写（`Student`、`HelloWorld`）|
| 成员变量 | 小驼峰，首字母小写（`studentName`）|
| 成员方法 | 小驼峰，首字母小写（`getScore()`）|

## 4. 创建对象

### 语法

```java
// 通过 new 关键字创建对象
类名 对象名 = new 类名();
```

### 使用对象的成员

```java
Student s1 = new Student();    // 创建对象

s1.name = "张三";               // 访问属性（赋值）
s1.age = 18;

System.out.println(s1.name);   // 访问属性（取值）
s1.study();                    // 调用方法
```

### 同一个类可以创建多个对象

```java
Student s1 = new Student();
Student s2 = new Student();

s1.name = "张三";
s2.name = "李四";

s1.sayHi();    // 大家好，我是张三
s2.sayHi();    // 大家好，我是李四
```

> 每个对象有**独立**的属性空间，互不干扰。

## 5. 对象在内存中的表示

Java 的内存分为三个主要区域：

### 栈内存（Stack）

- 存储**局部变量**（包括对象引用变量）
- 方法调用时分配，方法结束自动释放
- 特点是**速度快、容量小**

### 堆内存（Heap）

- 存储**new 出来的对象**（包括对象的成员变量）
- 对象不再使用时，由 **GC（垃圾回收器）** 自动回收
- 特点是**速度较慢、容量大**

### 方法区（Method Area）

- 存储**类的信息**（类名、方法定义、成员变量定义）
- 存储**静态成员**、常量池等
- 类加载时放入，程序结束时释放

### 对象创建的内存过程

```
                      方法区 (Method Area)
         ┌──────────────────────────────────┐
         │  Student.class                   │
         │   - name: String                 │
         │   - age: int                     │
         │   - study() 方法代码              │
         └──────────────────────────────────┘
                      ↑ 加载
                      │
栈 (Stack)            │        堆 (Heap)
┌────────────┐       │    ┌──────────────────┐
│ s1 (地址)   │──────┘    │  Student 对象     │
│  → 0x7c4   │           │  name = "张三"    │
│            │           │  age = 18         │
│ s2 (地址)   │           │                   │
│  → 0x9a2   │──────┐    └──────────────────┘
└────────────┘      │    ┌──────────────────┐
                    └──→ │  Student 对象     │
                         │  name = "李四"    │
                         │  age = 20         │
                         └──────────────────┘
```

### 步骤详解

```
1. 编译：.java → .class（字节码文件）
2. 加载：JVM 将 Student.class 加载到方法区
3. new：在堆内存中开辟空间给 Student 对象
4. 初始化：成员变量赋默认值（name = null, age = 0）
5. 赋值：执行代码中的赋值语句（name = "张三"）
6. 引用：栈中的 s1 变量保存对象的地址（指向堆中的对象）
```

> **关键理解：** `s1` 变量存的是对象的**地址（引用）**，不是对象本身。  
> 通过 `s1.name` 实际上是 "通过地址找到对象，再访问对象的 name 属性"。

## 6. 封装思想

### 什么是封装

**封装（Encapsulation）** 是面向对象三大特征之一，指的是：

> 将类的属性和方法包装在类内部，对外隐藏实现细节，仅暴露必要的访问接口。

### 如何实现封装

Java 通过 **访问控制修饰符** 来实现封装：

```java
public class Person {
    // private 私有化成员变量——外部不能直接访问
    private String name;
    private int age;

    // 对外提供公共的 getter/setter 方法
    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;    // this 表示当前对象的属性
    }

    public int getAge() {
        return age;
    }

    public void setAge(int age) {
        // 可以在 setter 中加入校验逻辑
        if (age >= 0 && age <= 150) {
            this.age = age;
        } else {
            System.out.println("年龄不合法！");
        }
    }
}
```

### 封装的优点

| 优点 | 说明 |
|------|------|
| **安全性** | 防止外部随意修改属性，可以加入校验逻辑 |
| **隐藏细节** | 使用者无需关心内部实现 |
| **可维护性** | 修改内部实现不影响外部调用代码 |
| **复用性** | 封装好的类可以重复使用 |

### 没有封装 vs 有封装

```java
// ❌ 没有封装——直接暴露属性
Student s = new Student();
s.age = -5;     // 不合法的年龄也能赋值，不合理

// ✅ 有封装——通过 setter 校验
Person p = new Person();
p.setAge(-5);   // 输出"年龄不合法！"，拒绝赋值
```

### this 关键字

`this` 表示当前对象的引用，用于区分成员变量和局部变量：

```java
public void setName(String name) {
    this.name = name;  // this.name 是成员变量，= 右边的 name 是参数
}
```

## 7. 面向对象编程概述

### 面向过程 vs 面向对象

| 对比 | 面向过程（POP） | 面向对象（OOP） |
|------|---------------|---------------|
| 核心 | 过程（函数） | 对象 |
| 思路 | 关注"怎么做" | 关注"谁来做" |
| 组织 | 按功能拆分步骤 | 按对象拆分职责 |
| 语言 | C、Pascal | Java、C++、Python |

### 面向对象三大特征

| 特征 | 说明 | 类比 |
|------|------|------|
| **封装** | 隐藏内部实现，暴露接口 | 遥控器——按按钮就行，不用管内部电路 |
| **继承** | 子类复用父类的属性和方法 | 遗传——子女继承父母的特征（后续学习）|
| **多态** | 同一行为在不同对象上有不同实现 | 都是"叫"，狗是汪汪，猫是喵喵（后续学习）|

### 面向对象的思考方式

```
洗衣机洗衣服（面向过程）：
    1. 打开洗衣机门
    2. 放入衣服
    3. 倒入洗衣液
    4. 关上门
    5. 启动洗涤
    6. 等待完成

洗衣机洗衣服（面向对象）：
    1. 创建洗衣机对象
    2. 洗衣机.开门()
    3. 洗衣机.放入衣服(衣服)
    4. 洗衣机.倒洗衣液(洗衣液)
    5. 洗衣机.关门()
    6. 洗衣机.启动()
    7. 洗衣机.等待完成()
```
