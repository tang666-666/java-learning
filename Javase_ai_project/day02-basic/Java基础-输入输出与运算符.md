## 1. 输出 System.out.println

Java 中最基本的输出方式：

```java
System.out.println("hello world");  // 输出内容并换行
System.out.print("hello");          // 输出内容不换行
System.out.printf("%d", 10);        // 格式化输出（类似 C 的 printf）
```

| 方法 | 特点 |
|------|------|
| `println()` | 输出后**自动换行**（最常用） |
| `print()` | 输出后**不换行** |
| `printf()` | **格式化**输出（类似 C 语言） |

### 常见转义字符

```java
System.out.println("第一行\n第二行");     // \n 换行
System.out.println("他说：\"你好\"");     // \" 输出双引号
System.out.println("路径：C:\\Users");    // \\ 输出反斜杠
```

## 2. 输入 Scanner

`Scanner` 是 Java 提供的标准输入工具，用于接收用户在控制台的输入。

### 使用步骤（三步）

```java
// 1. 导包（告诉 Java 要用哪个工具）
import java.util.Scanner;

// 2. 创建对象（准备好工具）
Scanner sc = new Scanner(System.in);

// 3. 获取用户输入（调用方法读取数据）
int age = sc.nextInt();        // 读取一个整数
String name = sc.next();       // 读取一个字符串（遇到空格停止）
String line = sc.nextLine();    // 读取一整行（包括空格）
```

### 常用方法

| 方法 | 用途 |
|------|------|
| `nextInt()` | 读取用户输入的整数 |
| `nextDouble()` | 读取用户输入的小数 |
| `next()` | 读取字符串（遇到空格/回车停止） |
| `nextLine()` | 读取一整行（包括空格，遇到回车停止） |
| `nextBoolean()` | 读取布尔值 |

### 示例

```java
import java.util.Scanner;

public class InputDemo {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.println("请输入姓名：");
        String name = sc.next();

        System.out.println("请输入年龄：");
        int age = sc.nextInt();

        System.out.println("你好，" + name + "，你今年" + age + "岁！");

        sc.close();  // 关闭 Scanner，释放资源（规范操作）
    }
}
```

> **注意：** `next()` 遇到空格会停止读取；想读包含空格的整句话要用 `nextLine()`。  
> 另外，`nextInt()` 后面接 `nextLine()` 可能有换行符残留问题，初学阶段注意区分。

## 3. 算术运算符

| 运算符 | 名称 | 示例 | 结果 |
|--------|------|------|------|
| `+` | 加法 | `10 + 3` | `13` |
| `-` | 减法 | `10 - 3` | `7` |
| `*` | 乘法 | `10 * 3` | `30` |
| `/` | 除法（取商） | `10 / 3` | `3`（整数除法） |
| `%` | 取余（取模） | `10 % 3` | `1` |

### 整数除法 vs 小数除法

```java
System.out.println(10 / 3);     // 输出 3（整数除法，舍弃小数部分）
System.out.println(10.0 / 3);   // 输出 3.33333...（浮点数除法）
System.out.println(10 / 3.0);   // 输出 3.33333...（浮点数除法）
```

> **关键：** 两个整数相除结果还是整数（直接舍去小数），想让结果是小数，至少一个操作数要为小数。

## 4. "+" 的字符串连接符作用

在 Java 中，`+` 有两种身份：
- **两边都是数值** → 算术加法
- **任意一边是字符串** → **连接符**，将两边拼接成字符串

### 规则

```java
int a = 10;
System.out.println("abc" + a);          // "abc10"（数字被转为字符串拼接）
System.out.println(a + 5);              // 15（两边都是数值，做算术加法）
System.out.println("itheima" + a + 'a'); // "itheima10a"（左→右，字符串+数字→字符串，再+字符→字符串）
System.out.println(a + 'a' + "itheima"); // "107itheima"（先算术：10 + 97 = 107，再拼接字符串）
```

### 关键规律

```
遇到字符串之前：做算术运算
遇到字符串之后：后面全部做拼接
```

| 表达式 | 执行顺序 | 结果 |
|--------|---------|------|
| `1 + 2 + "abc"` | 先 1+2=3，再 3+"abc" | `"3abc"` |
| `"abc" + 1 + 2` | 先 "abc"+1="abc1"，再+"2" | `"abc12"` |
| `1 + "abc" + 2` | 先 1+"abc"="1abc"，再+"2" | `"1abc2"` |

## 5. 自增自减运算符

| 运算符 | 名称 | 示例 | 说明 |
|--------|------|------|------|
| `++a` | 前置自增 | 先加 1，后使用 | `a=1; b=++a;` → a=2, b=2 |
| `a++` | 后置自增 | 先使用，后加 1 | `a=1; b=a++;` → a=2, b=1 |
| `--a` | 前置自减 | 先减 1，后使用 | `a=2; b=--a;` → a=1, b=1 |
| `a--` | 后置自减 | 先使用，后减 1 | `a=2; b=a--;` → a=1, b=2 |

### 口诀

> **符号在前，先加（减）再用；符号在后，先用再加（减）**

### 示例

```java
int a = 10;
System.out.println(a++);  // 输出 10（先用 a，再加 1）→ a 变为 11
System.out.println(++a);  // 输出 12（先加 1 到 12，再使用）

int b = 10;
int c = b++ + ++b;        // 10 + 12 = 22
// b++：先用 b=10，b 变为 11
// ++b：b 先加到 12，再使用
```

> **建议：** 初学阶段避免在复杂表达式中混用自增自减，容易混淆。单独一行使用最清晰。

## 6. 赋值运算符

### 基本赋值

```java
int a = 10;   // 将 10 赋值给变量 a
```

### 扩展赋值运算符

| 运算符 | 示例 | 等价于 | 说明 |
|--------|------|--------|------|
| `+=` | `a += 3` | `a = a + 3` | 加后赋值 |
| `-=` | `a -= 3` | `a = a - 3` | 减后赋值 |
| `*=` | `a *= 3` | `a = a * 3` | 乘后赋值 |
| `/=` | `a /= 3` | `a = a / 3` | 除后赋值 |
| `%=` | `a %= 3` | `a = a % 3` | 取余后赋值 |

### 扩展赋值自带强制类型转换

扩展赋值运算符**隐含了强制类型转换**，这是与普通赋值的关键区别：

```java
byte b = 10;
b = b + 5;    // ❌ 编译错误：byte + int → int，不能直接赋给 byte
b += 5;       // ✅ 等价于 b = (byte)(b + 5)，隐含强转

int i = 10;
i += 3.5;     // 等价于 i = (int)(i + 3.5) → 结果为 13
```

## 7. 关系运算符

关系运算符用于比较两个值，结果永远是 `boolean` 类型（`true` 或 `false`）。

| 运算符 | 名称 | 示例 | 结果 |
|--------|------|------|------|
| `>` | 大于 | `5 > 3` | `true` |
| `<` | 小于 | `5 < 3` | `false` |
| `>=` | 大于等于 | `5 >= 5` | `true` |
| `<=` | 小于等于 | `5 <= 3` | `false` |
| `==` | 等于 | `5 == 3` | `false` |
| `!=` | 不等于 | `5 != 3` | `true` |

### 注意事项

- **`==` 是判断相等**，不要写成 `=`（赋值）
- 关系运算符的结果是 `boolean`，常用于 `if` 判断和循环条件
- **浮点数比较**要小心精度问题

```java
int score = 85;
boolean isPass = score >= 60;    // true
System.out.println(isPass);      // 输出 true
```

## 8. 逻辑运算符

逻辑运算符用于连接多个 `boolean` 条件，结果还是 `boolean`。

### 基本逻辑运算符

| 运算符 | 名称 | 规则 | 示例 |
|--------|------|------|------|
| `&` | 逻辑与 | 两边都为 `true`，结果才为 `true` | `(5>3) & (5>1)` → `true` |
| `\|` | 逻辑或 | 一边为 `true`，结果就为 `true` | `(5>3) \| (5<1)` → `true` |
| `!` | 逻辑非 | 取反 | `!(5>3)` → `false` |
| `^` | 逻辑异或 | 两边相同为 `false`，不同为 `true` | `(5>3) ^ (5<1)` → `true` |

### 短路逻辑运算符

| 运算符 | 名称 | 规则 | 特点 |
|--------|------|------|------|
| `&&` | 短路与 | 同 `&`，但左边为 `false` 时右边不执行 | **效率更高，避免空指针** |
| `\|\|` | 短路或 | 同 `\|`，但左边为 `true` 时右边不执行 | **效率更高** |

### 短路 vs 非短路的区别

```java
int a = 10;
boolean result1 = (a > 5) && (++a > 10);  // 左边 true，右边执行，a 变为 11
boolean result2 = (a < 0) && (++a > 10);  // 左边 false，右边不执行（短路）
boolean result3 = (a < 0) & (++a > 10);   // 左边 false，右边照常执行（非短路）
```

### 常见用法

```java
// 判断一个数是否在范围内
int score = 85;
boolean isGood = score >= 80 && score <= 100;   // true（80~100 分之间）

// 判断是否满足任一条件
boolean canDiscount = isVIP || isBirthday;       // VIP 或生日，满足一个就优惠

// 取反
boolean isNotPass = !(score >= 60);              // 是否不及格
```

### 运算符优先级（逻辑部分）

```
!  >  &&  >  ||
```

## 9. 三目运算符

### 语法

```java
条件表达式 ? 值1 : 值2
```

如果条件为 `true`，取 `值1`，否则取 `值2`。

### 示例

```java
int a = 10, b = 20;
int max = a > b ? a : b;       // max = 20

int score = 75;
String result = score >= 60 ? "及格" : "不及格";   // "及格"

// 可以嵌套使用（不推荐嵌套太深）
int x = 5, y = 10, z = 3;
int max3 = x > y ? (x > z ? x : z) : (y > z ? y : z);
```

> **对比 C 语言：** 三目运算符的用法和 C 完全一致，零学习成本。

### 应用场景

```java
// 取两个数中的较大值
int max = a > b ? a : b;

// 判断奇偶
String type = num % 2 == 0 ? "偶数" : "奇数";

// 判空时的默认值
String displayName = name != null ? name : "匿名用户";
```
